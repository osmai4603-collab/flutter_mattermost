# Get file metadata headers

Original OpenAPI operationId: `HeadFile`
- Method: `HEAD`
- Path: `/api/v4/files/{file_id}`
- Summary: Get file metadata headers
- Description: Performs the same permission and existence checks as getting a file, but returns headers only.

- Tags: files

## Parameters
- `file_id` (path, required, string) - The ID of the file to get

## Request body
No request body.
