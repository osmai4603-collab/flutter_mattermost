# Download an export file

Original OpenAPI operationId: `DownloadExport`
- Method: `GET`
- Path: `/api/v4/exports/{export_name}`
- Summary: Download an export file
- Description: Downloads an export file.


__Minimum server version__: 5.33

##### Permissions

Must have `manage_system` permissions.

- Tags: exports

## Parameters
- `export_name` (path, required, string) - The name of the export file to download
