# Get thumbnail metadata headers

Original OpenAPI operationId: `HeadFileThumbnail`
- Method: `HEAD`
- Path: `/api/v4/files/{file_id}/thumbnail`
- Summary: Get thumbnail metadata headers
- Description: Performs the same permission and existence checks as getting a thumbnail, but returns headers only.

- Tags: files

## Parameters
- `file_id` (path, required, string) - The ID of the file to get

## Request body
No request body.
