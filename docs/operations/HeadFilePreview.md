# Get preview metadata headers

Original OpenAPI operationId: `HeadFilePreview`
- Method: `HEAD`
- Path: `/api/v4/files/{file_id}/preview`
- Summary: Get preview metadata headers
- Description: Performs the same permission and existence checks as getting a preview, but returns headers only.

- Tags: files

## Parameters
- `file_id` (path, required, string) - The ID of the file to get
