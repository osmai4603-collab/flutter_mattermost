# Get an upload session

Original OpenAPI operationId: `GetUpload`
- Method: `GET`
- Path: `/api/v4/uploads/{upload_id}`
- Summary: Get an upload session
- Description: Gets an upload session that has been previously created.

##### Permissions
Must be logged in as the user who created the upload session.

- Tags: uploads

## Parameters
- `upload_id` (path, required, string) - The ID of the upload session to get.

## Request body
No request body.
