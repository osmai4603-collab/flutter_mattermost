TeamStats
---------

Fields:

- `team_id`: string | nullable
- `total_member_count`: integer | nullable

JSON Schema (minimal):

{
	"$id": "https://example.com/schemas/team_stats.json",
	"title": "TeamStats",
	"type": "object",
	"properties": {
		"team_id": { "type": ["string", "null"], "description": "ID of the team" },
		"total_member_count": { "type": ["integer", "null"], "description": "Total number of members in the team" }
	},
	"required": []
}

Example JSON:

{
	"team_id": "t-123",
	"total_member_count": 42
}

Suggested optional fields:

- `active_member_count` (integer): currently active/online members.
- `guest_count` (integer): number of guest users in the team.
- `channel_count` (integer): number of channels belonging to the team.
- `last_updated_at` (string, ISO8601): timestamp when stats were last calculated.

Notes:

- In the codebase `team_id` is often represented as `String?` and `total_member_count` as `int?` (nullable).
- Add any of the suggested optional fields if you need more metrics exposed.
