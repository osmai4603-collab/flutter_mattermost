# TeamReviewerConfig

Original OpenAPI schema: `TeamReviewerConfig`

No description available in the official OpenAPI schema.

## Fields

- `Enabled`: boolean (required)
  - Whether team-specific reviewers are enabled for this team
- `ReviewerIds`: array (required)
  - List of user IDs designated as reviewers for this specific team

## Example JSON

```json
{"Enabled": False, "ReviewerIds": []}
```
