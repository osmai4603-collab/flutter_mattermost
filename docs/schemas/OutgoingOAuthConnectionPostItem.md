- `credentials_password`: string

- `oauth_token_url`: string
  - The OAuth token URL of the outgoing OAuth connection.
- `grant_type`: string
  - The grant type of the outgoing OAuth connection.
- `audiences`: string
  - The audiences of the outgoing OAuth connection.
