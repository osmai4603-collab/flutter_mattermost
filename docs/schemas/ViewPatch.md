# ViewPatch

Original OpenAPI schema: `ViewPatch`

Fields that can be updated on a view via PATCH

## Fields

- `title`: string
- `description`: string
- `sort_order`: integer
- `props`: object
  - Arbitrary key-value properties for the view

## Example JSON

```json
{"title": ""string"", "description": ""string"", "sort_order": 0, "props": {}}
```
