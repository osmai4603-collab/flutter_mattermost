# RecapLimitStatus

Original OpenAPI schema: `RecapLimitStatus`

The current user's recap limit status including usage and cooldown information

## Fields

- `effective_limits`: EffectiveRecapLimits
- `daily`: DailyUsageStatus
- `cooldown`: CooldownStatus

## Example JSON

```json
{"effective_limits": "EffectiveRecapLimits", "daily": "DailyUsageStatus", "cooldown": "CooldownStatus"}
```
