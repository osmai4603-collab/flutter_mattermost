# ChannelMemberCountByGroup

Original OpenAPI schema: `ChannelMemberCountByGroup`

An object describing group member information in a channel

## Fields

- `group_id`: string
  - ID of the group
- `channel_member_count`: number
  - Total number of group members in the channel
- `channel_member_timezones_count`: number
  - Total number of unique timezones for the group members in the channel

## Example JSON

```json
{"group_id": ""string"", "channel_member_count": 0.0, "channel_member_timezones_count": 0.0}
```
