# دليل استخدام محرر الدردشة

دليل عملي لمحرر رسائل Mattermost (عميل Flutter Desktop).

## 1) بنية المحرر

من الأسفل إلى الأعلى:

- **حقل الكتابة**: متعدد الأسطر (حتى 8 أسطر) مع placeholder يتغيّر حسب السياق (رسالة جديدة / ردّ في موضوع / تعديل منشور)، وزر إرسال عند اليمين.
- **شريط التنسيق**: ثلاث مجموعات من الأزرار يفصلها خط رفيع (موضّحة في القسم 2).
- **طبقة السحب/الإفلات** للملفات: إطار نابض يظهر عند السحب ويُعرض فيه عدد الملفات المتبقية.
- عند تفعيل **المعاينة** تظهر لوحة `<PreviewPane>` فوق المحرر.

## 2) التنسيق

اختر نصاً ثم انقر الزر، أو ضع المؤشر في السطر المطلوب واضغطه لتطبيقه على السطر كاملاً.

| المجموعة | الأداة |
|---|---|
| أساسية | عريض، مائل، خط أثناء، كود سطر، رابط |
| اقتباس وقوائم | اقتباس `>`, قائمة نقطية، قائمة مرقّمة، قائمة مهام `- [ ]` |
| متقدمة | عناوين H1/H2/H3، جدول Markdown، خط فاصل `---` |

ملاحظات:

- الزر يصبح **نشطاً** (ملوّناً بأزرق الرابط) عندما يكون المؤشر داخل نفس التنسيق.
- قائمة العناوين تتحقق من مستوى العنوان الحالي لتسمح بالتبديل بين المستويات بضغطة واحدة.
- **tooltip** كل زر يعرض اختصاره.

## 3) إرسال الرسالة

- **Enter** يدرج سطراً جديداً (مثل Discord)، **Ctrl+Enter** يرسل — ويمكن الإرسال أيضاً عبر زر الإرسال.
- عند الإرسال بـ **Ctrl+Enter** داخل كتلة كود مفتوحة، تُغلق الكتلة (```) تلقائياً ثم تُرسل الرسالة.
- أثناء الإرسال يستبدل زر الإرسال بدائرة تحميل.
- عند فشل الإرسال يظهر **شريط خطأ** أحمر فيه خياران:
  - **إعادة المحاولة**: يعيد الإرسال متجاهلاً الخطأ السابق.
  - **إغلاق**: يخفي الشريط مع بقاء المسودة.
- **سجل الرسائل**: **Ctrl+↑ / Ctrl+↓** للتنقل في آخر 100 رسالة أرسلتها.

## 4) الملفات والمرفقات

- **Ctrl+U**: فتح منتقي الملفات. تظهر الملفات كمعاينات (الصور بمصغّرتها الفعلية) مع مؤشر تقدم، ولا تُرسل الرسالة إلا بعد اكتمال رفع جميع المرفقات.
- **Ctrl+V** (لصق): صورة الحافظة تُرفع تلقائياً دون إيقاف لصق النص الافتراضي.
- **سحب وإفلات** الملفات فوق منطقة السحب.
- حدّ أقصى لعدد المرفقات تمنعه عدّاد "المرفقات المتبقية".

## 5) الميزات الذكية

- **مسودات تلقائية**: كل حرف يُحفظ محلياً (بعد مهلة ~300ms) ومفتاح توفير منفصل لكل قناة وموضوع. عند العودة للقناة تُستعاد المسودة، وتُحذف من التخزين عند الإرسال أو الإفراغ.
- **مؤشرات الكتابة**: تظهر أسماء المستخدمين الذين يكتبون، وفق ترتيب: nickname ← الاسم الكامل ← username، وتُخفى تلقائياً بعد 6 ثوانٍ من آخر حركة لديهم. لا يُرسل إشارة كتابة عندما يكون المحرر فارغاً.
- **Markdown الحية (إغلاق الفواصل)**: اكتب `**` أو `~~` أو `` ` `` في نهاية النص فيُدرج الفاصل الإغلاقي تلقائياً ويبقى المؤشر في المنتصف. لا يتداخل مع `***` ولا كتل البرمجة (```.
- **الإكمال التلقائي**: طبقة تطفو فوق المحرر تقترح المستخدمين/القنوات/الأوامر؛ التنقل بها ↓/↑ ثم Enter للتحديد وEscape للإغلاق.

## 6) الإيموجي

زر وجه مبتسم يفتح طبقة منسدلة، أو **Ctrl+Alt+E** / **Ctrl+Shift+E**. الإيموجي يُدرج مع مسافة حوله تلقائياً لتسهيل التتابع.

## 7) المعاينة

**Ctrl+Alt+P** (أو زر العين في الشريط) تفتح عرضاً معالَجاً لرسالتك. أثناء فتح المعاينة يُعطَّل الزر والإرسال والتنسيق، وتُفتح الروابط في المتصفح الخارجي.

## 8) جدول الاختصارات

| الوظيفة | الاختصار |
|---|---|
| إرسال الرسالة | **Ctrl+Enter** |
| سطر جديد | **Enter** |
| عريض | **Ctrl+B** |
| مائل | **Ctrl+I** |
| خط أثناء | **Alt+Shift+X** |
| كود سطر | **Ctrl+Alt+C** |
| رابط | **Ctrl+Alt+K** (أو **Ctrl+K** عند وجود اختيار) |
| قائمة مرقّمة | **Alt+Shift+7** |
| قائمة نقطية | **Alt+Shift+8** |
| اقتباس | **Alt+Shift+9** |
| معاينة | **Ctrl+Alt+P** |
| إيموجي | **Ctrl+Shift+E** / **Ctrl+Alt+E** |
| منتقي الملفات | **Ctrl+U** |
| لصق صورة من الحافظة | **Ctrl+V** |
| سجل الرسائل | **Ctrl+↑ / Ctrl+↓** |
| تعديل آخر منشور | **↑** (على محرر فارغ) |
| ردّ على آخر منشور | **Shift+↑** (على محرر فارغ) |
| إغلاق الإيموجي/إلغاء التركيز | **Escape** |
