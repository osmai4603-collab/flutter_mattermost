# osm_ui_components

حزمة حزمة أدوات ومكونات بناء الواجهات المشتركة (Shared UI Building Blocks & Infrastructure) لمشاريع Flutter، والمستوحاة من معمارية تطبيق **Mattermost Webapp**.

## المكونات المضمنة في هذه الحزمة:

1. **`CompassTheme`**: نظام الثيمات والألوان المتكامل.
2. **`AppGenericDialog`**: هيكل المودال والنوافذ المنبثقة الموحد.
3. **`AppModalService`**: التحكم البرمجي المركزي في فتح وإغلاق النوافذ.
4. **`AppTextField`**: مدخل النصوص المؤطر المعياري.
5. **`AppAutosizeTextArea`**: مدخل النصوص المتمدد تلقائياً.
6. **`AppUserAvatar`**: الصورة الشخصية مع شارة حالة الاتصال.
7. **`AppUserStatusBadge`**: شارة أيقونة حالة الاتصال المستقلة.
8. **`AppUserProfilePopover`**: بطاقة تفاصيل المستخدم الطافية.
9. **`AppSkeletonLoader`**: عنصر التحميل الهيكلي (Shimmer Loading).
10. **`AppVirtualizedList`**: محرك القوائم الافتراضية فائقة الأداء.
11. **`AppRichTextEditor`**: محرر وشريط تنسيق النصوص الغنية.
